# منصة الاختبارات المدرسية – نسخة الاستخدام (الإصدار 2.5)

منصة اختبارات ثنائية اللغة (عربي / إنجليزي) للمدارس: لوحة تحكم للمديرة، المعلمات والطلاب، بنك أسئلة،
أسئلة بالصور والتوصيل وأكمل الفراغ وترتيب الكلمات والكتابة باليد، تصحيح آلي ويدوي، طباعة الأوراق، ونسخ احتياطي.

> هذه **نسخة الاستخدام**: تبدأ فارغة بدون أي حسابات تجريبية. عند أول فتح للموقع تظهر صفحة
> **إعداد حساب المديرة**. (للتجربة فقط: ضعي المتغير `DEMO_SEED=1` قبل أول تشغيل على قاعدة بيانات فارغة.)

---

## 1) الرفع على GitHub (من VS Code)

1. افتحي مجلد المشروع في VS Code (**File → Open Folder**).
2. من الشريط الجانبي اختاري **Source Control** (أيقونة الفروع) أو اضغطي `Ctrl+Shift+G`.
3. اضغطي **Publish Branch / Publish to GitHub** وسجّلي الدخول بحساب GitHub عند الطلب.
4. اختاري **Publish to GitHub private repository** (مستودع خاص – موصى به).

ملف `.gitignore` يمنع رفع قاعدة البيانات المحلية والصور وكلمة السر (`instance/`)، فلا تُرفع أي بيانات للطلاب.

> بديل بدون VS Code: ثبّتي **GitHub Desktop** ← File → Add local repository ← اختاري المجلد ← Publish repository.

---

## 2) النشر على Vercel

Vercel لا يحفظ الملفات على الخادم، لذلك يستخدم الموقع على Vercel قاعدة بيانات **PostgreSQL** (مجانية من Neon)،
وتُحفظ الصور وملفات الطلاب داخل قاعدة البيانات نفسها. لا حاجة لتعديل أي كود.

1. ادخلي إلى [vercel.com](https://vercel.com) بحساب GitHub ← **Add New → Project** ← اختاري المستودع ← **Import**.
   - Framework Preset: **Other** (اتركي الإعدادات كما هي).
2. قبل الضغط على Deploy أو بعده: من صفحة المشروع ← **Storage** ← **Create Database** ← اختاري **Neon (Postgres)**
   ← Region قريبة (مثل Frankfurt `fra1`) ← اربطيها بالمشروع. سيضيف Vercel المتغير `DATABASE_URL` تلقائيًا.
3. **Settings → Environment Variables** وأضيفي:
   - `SECRET_KEY` = نص عشوائي طويل (مثال: نتيجة الأمر `python -c "import secrets; print(secrets.token_hex(32))"`).
4. **Deployments → Redeploy** (حتى يقرأ المتغيرات الجديدة).
5. افتحي رابط الموقع ← تظهر صفحة **إعداد حساب المديرة** ← أنشئي الحساب.
6. (اختياري) من **الإعدادات ← إضافة النماذج وتعبئة بنك الأسئلة** لإضافة الاختبارات النموذجية.

كل تعديل تدفعينه (Push) إلى GitHub يُنشر تلقائيًا على Vercel.

### نقل البيانات من الجهاز إلى Vercel
في الموقع المحلي: **النسخ الاحتياطي ← تنزيل نسخة احتياطية**، ثم في موقع Vercel: **النسخ الاحتياطي ← الاستعادة من ملف**.
(حجم الملف المرفوع على Vercel حتى 4.5 ميغابايت تقريبًا؛ إذا كانت النسخة أكبر بسبب الصور، أضيفي الصور لاحقًا من الموقع.)

### ملاحظات Vercel
- حجم أي ملف مرفوع (صورة، صوت، ملف طالب) حتى **4 ميغابايت**.
- النسخ الاحتياطي التلقائي على الخادم غير متاح على Vercel: نزّلي نسخة احتياطية من لوحة التحكم بانتظام
  (Neon يحتفظ أيضًا بسجل استرجاع خاص به).
- الرابط يعمل على https، لذا تسجيل الصوت من الميكروفون يعمل على الجوال والآيباد.

## 3) التشغيل على جهاز المدرسة (بدون إنترنت أو قبل النشر)

### ويندوز
1. ثبّتي **Python 3.10+** (مع خيار **Add Python to PATH**).
2. اضغطي مرتين على **`run_windows.bat`** ← يظهر رابط للكمبيوتر (`http://localhost:8000`) ورابط للجوال والآيباد على نفس الشبكة.

### VS Code
1. **Terminal → Run Task → «1) إعداد البيئة»** (مرة واحدة).
2. **Ctrl+Shift+P → Python: Select Interpreter** ← `.venv`.
3. **F5** ← «▶ تشغيل الموقع» ← `http://localhost:3000`.

محليًا تُحفظ البيانات في مجلد `instance/` (قاعدة بيانات SQLite، الصور، النسخ الاحتياطية التلقائية كل 24 ساعة).

## المتغيرات (Environment Variables)
| المتغير | الوصف |
|---|---|
| `DATABASE_URL` | رابط PostgreSQL (يضيفه Vercel/Neon تلقائيًا). بدونه تُستخدم SQLite محليًا. |
| `SECRET_KEY` | مفتاح توقيع تسجيل الدخول (مطلوب على Vercel؛ محليًا يُنشأ تلقائيًا). |
| `DEMO_SEED` | `1` لتحميل بيانات تجريبية على قاعدة فارغة. الافتراضي `0`. |
| `EXPORT_UTC_OFFSET_HOURS` | فرق التوقيت في ملفات إكسل (السعودية = 3). |

## أوامر مفيدة (محليًا)
```
python -m server.manage create-admin <username> <password> "الاسم"
python -m server.manage set-password <username> <password>
python -m server.manage backup
```

## هيكل المشروع
```
api/index.py        نقطة الدخول على Vercel
vercel.json         إعداد Vercel
server/             التطبيق (Flask): الصفحات، القوالب، الملفات الثابتة
serve.py            تشغيل الإنتاج على جهاز محلي (waitress)
run_windows.bat     تشغيل بنقرة على ويندوز
```
